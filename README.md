# Unfold Dhaka

A Greater Dhaka city explorer inspired by Cholo Puran Dhaka, built with Next.js, TypeScript, Three.js and OpenStreetMap.

## Roadmap

1. Responsive city discovery interface, searchable places and interactive OpenStreetMap.
2. Three.js hybrid 3D view with illustrative city massing and curated landmarks.
3. Curated routes and trip planning.
4. Expand and verify the Greater Dhaka places dataset, including history, food, culture and practical visitor information.
5. Add real sourced building footprints, route services, accessibility and SEO improvements.

## Current scope

The first release is a prototype with a small starter dataset. The 3D scene is illustrative and must not be mistaken for surveyed building geometry. Place details and coordinates should be verified before production use.

## Local development

Install dependencies with `npm install`, then run `npm run dev`.

OpenStreetMap attribution must remain visible. Review the OpenStreetMap tile usage policy before scaling traffic or implementing offline maps: https://operations.osmfoundation.org/policies/tiles/.
